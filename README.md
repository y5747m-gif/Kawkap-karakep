# كوكب كراكيب
منصة Marketplace عربية، RTL وMobile First، لبيع وشراء وإعادة استخدام المواد المستعملة والقابلة للتدوير.

## التشغيل
```bash
npm install
cp .env.example .env.local
npm run dev
```
ثم افتح `http://localhost:5173`. للإنتاج: `npm run build`.

## البنية
- `src/main.jsx`: الواجهات، التنقل، السلة، المفضلة والنماذج التفاعلية.
- `src/data.js`: بيانات العرض المنفصلة عن الإنتاج.
- `src/styles.css`: نظام التصميم المتجاوب والوضع الداكن.
- `supabase/schema.sql`: مخطط PostgreSQL وسياسات RLS الأساسية.
- `public/`: الشعار، PWA manifest، Service Worker وSEO.

## Supabase
1. أنشئ مشروعًا وشغّل `supabase/schema.sql` في SQL Editor.
2. فعّل Email/Phone في Authentication، وأضف رابط الموقع إلى Redirect URLs.
3. أنشئ bucket باسم `product-images`، بحد 8 صور وMIME: `image/jpeg,image/png,image/webp`، وأضف سياسات الرفع للمستخدم الموثق.
4. ضع URL وanon key في `.env.local`. لا تضع service-role key في الواجهة.

## الخرائط
الواجهة جاهزة لطبقة مزود. استخدم OpenStreetMap عبر Leaflet أو ضع Mapbox public token في `VITE_MAPBOX_TOKEN`. يجب حفظ الإحداثيات الفعلية فقط بعد موافقة المستخدم؛ بيانات العرض الحالية ليست مواقع إنتاج.

## النشر على Vercel
اربط المستودع، اختر Vite، Build Command: `npm run build`، Output: `dist`، ثم أضف متغيرات البيئة. يحتوي `vercel.json` على rewrite من `/(.*)` إلى `/index.html` لتعمل روابط SPA المباشرة وإعادة تحميل الصفحات دون خطأ 404. سجّل نطاق الإنتاج في Supabase Auth.

## الأمان والإنتاج
RLS مفعّل كبداية. أضف Edge Functions للـ rate limiting، فحص الملفات server-side، صلاحيات admin claims، والتحقق بـ Zod قبل الإطلاق. الدفع الإلكتروني غير مفعل؛ الواجهة تعرض الدفع عند الاستلام فقط. الصور التجريبية من Unsplash وتُستبدل بملفات Storage في الإنتاج.

## الهيرو السينمائي ثلاثي الأبعاد
الصفحة الرئيسية تفتح على مشهد WebGL حيّ للوحة مفاتيح ميكانيكية وردية داخل بيئة كحلية سينمائية
(إضاءة زرقاء/سماوية + انعكاسات ماجنتا + عمق ميدان حقيقي + توهّج).

### السيناريو (٢٤ ثانية، يُعاد تلقائيًا)
| الزمن | المشهد |
|---|---|
| ٠ – ٥٫٢ | انزلاق ماكرو ناعم فوق الكيكابس الوردية |
| ٥٫٢ – ٧٫٦ | الاستقرار والتركيز على المفتاح البطل |
| ٧٫٦ – ١٢٫٦ | ارتفاع رأسي للكيكاب ومكوّنات السويتش (exploded view) مع خيوط ضوء زرقاء |
| ١٢٫٦ – ١٦٫٦ | صعود الكاميرا مع دوران خفيف وتغيير بؤرة (rack focus) |
| ١٦٫٦ – ٢٠ | إعادة التجميع مع نبضة ضوء زرقاء |
| ٢٠ – ٢٤ | لقطة بطل ثلاثة أرباع للوحة كاملة |

### الملفات
- `src/scene/config.js`: **كل** الألوان والأبعاد والتخطيط ومفاتيح الكاميرا والتوقيتات. لمطابقة لوحة مرجعية أخرى عدّل هذا الملف وحده.
- `src/scene/keyboard.js`: بناء الجسم واللوحة والكيكابس المنحوتة (حروف لاتينية + عربية).
- `src/scene/switchParts.js`: مكوّنات السويتش، خيوط الضوء، ونبضة إعادة التجميع.
- `src/scene/cinematic.js`: البيئة، الإضاءة، ما بعد المعالجة (Bloom + Bokeh)، الخط الزمني، ومسجّل الفيديو.
- `src/components/KeyboardHero.jsx`: التركيب في React مع شريط التحكم.

### الأداء وإمكانية الوصول
- تحميل كسول (`lazy`) لحزمة three، فلا تتأثر سرعة الصفحة الأولى.
- جودة تلقائية: الجوال يخفض DPR ويلغي عمق الميدان والظلال.
- يتوقف الرسم عند إخفاء التبويب أو خروج المشهد من الشاشة.
- `prefers-reduced-motion`: يُعرض إطار ثابت للقطة البطل.
- بلا WebGL: تظهر صورة `public/storyboard/hero-poster.jpg`.

### تصدير فيديو
زر «تصدير فيديو» في شريط التحكم يسجّل دورة كاملة (٢٤ ثانية) عبر `MediaRecorder`
وينزّلها كملف WebM مباشرة من المتصفح.

### لوحة القصة
الكادرات في `public/storyboard/` مُصدَّرة من المشهد نفسه. لإعادة توليدها:
```bash
npm i -D puppeteer-core @sparticuz/chromium   # أدوات تطوير اختيارية
npm run dev                                   # في طرفية أخرى
npm run storyboard
```
